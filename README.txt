Zoony Mix

A private local playlist mixer designed for iPhone Safari.

Features
- Import multiple local audio files
- Reorder tracks
- Remove tracks
- Crossfade from 0–15 seconds
- Preview the continuous mix
- Export the entire result as one WAV file
- Works locally; files are not uploaded
- Add to Home Screen as a PWA

Quick start
1. Host these files on any static host (Netlify, GitHub Pages, Cloudflare Pages, etc.).
2. Open the site in Safari on iPhone.
3. Share > Add to Home Screen.
4. Add songs from Files.
5. Reorder them, choose crossfade, preview, and Export WAV.

Note
Rendering many large WAV source files can use a lot of memory on iPhone Safari.
MP3/M4A/AAC source files are much more memory-friendly.
